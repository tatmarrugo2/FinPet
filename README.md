# FinPet 🐾

FinPet es un MVP académico desarrollado para el proyecto de aula de Ingeniería de Software.

## Descripción

FinPet busca ayudar a jóvenes y adultos jóvenes a llevar un registro sencillo de sus ingresos y gastos personales. La propuesta incorpora una mascota virtual que brinda retroalimentación contextual para motivar al usuario a mantener el hábito de registrar sus movimientos financieros.

## Funcionalidades del MVP

- Registro de ingresos.
- Registro de gastos.
- Clasificación por categorías.
- Consulta de movimientos.
- Cálculo de ingresos, gastos y saldo.
- Resumen de gastos por categoría.
- Comparación de gastos entre meses.
- Mascota virtual con mensajes de retroalimentación.
